# Barro’s Beatdown Patch Notes (3/24/26)
**Version 1.1 – “Serious Stuff” Update**

This is the second update for **Barro’s Beatdown**! This patch focuses on venue feature changes and implementation of new rules.

---

## Venue
- We now have lights outside on the walkway! Better lighting for photos and hanging out!
- Barro's Pizza has a new Pokémon Pinball machine! It's super cool!

### 🎥 Stream
We recently upgraded our stream setup so that it has a more stable connection. This means fewer dropped frames and higher bitrate potential.
- There is now a wired ethernet connection from the router to the stream setup.

### 🎮 Tournament Setups

## Rules
This is the most important part of the patch notes. Please read thoroughly.
You can access the full ruleset for Barro's Beatdown [here](https://github.com/BarrosBeatdown/Barro-s-Beatdown-Patch-Notes/blob/main/Rules.md).

It is every player's responsibility to read the rules and follow them. They will also be posted on every start.gg page.

Here are some updates to how controllers will work.
### 🎮 Controller Policy
- Notify the TO ASAP if your controller takes the audio of the setup.
- **Keyboards**
    - Keyboard users have been a thorn in the side for many Tournaments and Barro's Beatdown is no exception. We want to welcome as many different input methods as possible but there are limits to what we can accommodate so that we can run the tournament smoothly and without any technical difficulties.
    - All non-Windows Keyboards are banned.
    - If you are using a keyboard and use the "Keyboard Standalone Mode", it is your responsibility to turn it off before you leave the setup. Failure to do so, may result in a disqualification. Multiple offenses may result in a ban.
